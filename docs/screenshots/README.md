# Project screenshots

Store screenshots of MedSecure development, tests, terminal output, and Docker runs here.

Use descriptive filenames such as `01-environment-verification.png` and `02-log-parser-test.png`.

Before uploading, redact passwords, access tokens, private IP addresses when necessary, personal data, and any real patient information. Use synthetic data for demonstrations.

Reference images from the main README using relative paths such as `docs/screenshots/01-environment-verification.png`.
